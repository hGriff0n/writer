## Overview

The World Codex is the component responsible for managing world consistency. It acts as the single source of truth for all canonical facts, whether they are predefined by the user, imported from an existing universe (e.g., a historical setting, a public domain work, or a media franchise), or generated by the AI during the storytelling process. Its primary purpose is to provide a stable, queryable repository of lore to ensure that characters, locations, and events remain consistent. This component establishes the *policy* for world information: where it comes from, how it's structured, and how contradictions are handled.

## Identification Heuristics

*   **Custom World Cues:** "Let's define the factions," "I need to track my characters," referring to a "world bible" or "lore book."
*   **Import Cues:** "Let's set this in Victorian London," "This is a Star Wars fanfiction," "The story takes place in the Cthulhu Mythos universe."
*   **Generative Cues:** "You can make up the world as we go," "I don't have any specific lore in mind," "Let's discover the world through the story."
*   **Structural Cues:** User makes declarative statements about the *types* or *categories* of information to be tracked or imported (e.g., "For every location, I want to know its population," "We should only import characters from the original trilogy.")

## Component Synthesis Guide

The synthesis process for the World Codex begins with a fundamental choice of the source of lore. The user must be guided to one of two primary paths.

1.  **World Foundation**
    *   **Objective:** To establish a pre-existing body of knowledge (historical, fictional, etc.) as the baseline for the world's lore, or to explicitly delegate world creation to the AI.
    *   **Scope of Inquiry:**
        *   **Source Identification:** What is the foundational source of lore?
            *   Is it a real-world historical period? (e.g., `Ancient Rome, Late Republic`)
            *   Is it a specific media franchise or IP? (e.g., `Star Trek: The Next Generation`)
            *   Is it a public domain work? (e.g., `The Works of H.P. Lovecraft`)
            *   Is it to be AI-generated? (e.g., `Generative High Fantasy`)
        *   **Scope and Boundaries:** What are the limits of the import? (e.g., "Only use information from the original film trilogy," "Focus on the political climate of Paris in the 1880s," "Exclude the supernatural elements from the historical period.")
        *   **Rules of Deviation:** What is the policy for new or contradictory information? Can the story introduce elements that don't exist in the source canon? Are there specific elements of the canon that are explicitly being changed?
    *   **Strategic Focus:** The orchestrator must manage user expectations by defining clear boundaries. The goal is to prevent ambiguity. Probe for specificity on canon sources (e.g., "For Star Wars, are we using Legends or Disney canon?"). For generative worlds, establish the genre and core tropes to guide the generation. For historical settings, confirm the desired level of accuracy.
    *   **Minimal Viability Check:** The source of the World Foundation is unambiguously identified. If the source is external, basic rules regarding the scope of inclusion and the policy on deviation from canon have been stated. If the source is generative, a core genre or concept has been provided.

2.  **Custom Codex Schema**
    *   **Objective:** To design a bespoke structure for a completely original world, or to define specific additions and overrides on top of an established **World Foundation**.
    *   **Scope of Inquiry:**
        *   **Entity Categories:** What are the top-level types of entries? (e.g., `Characters`, `Locations`, `Factions`).
        *   **Properties & Attributes:** For each category, what fields of information should be tracked? (e.g., For `Characters`: `Faction Allegiance`, `Physical Description`).
        *   **Relationships:** How do entities relate to one another? (e.g., `[Character]` is `Member Of` `[Faction]`).
    *   **Strategic Focus:** This is identical to the previous version's "Codex Schema." Enforce precision, anticipate edge cases, and promote data normalization. If this schema is extending a **World Foundation**, the focus must be on how custom elements interact with the imported lore. For example, "How does your new `Magic` system interact with the established physics of the Star Trek universe you've imported?"
    *   **Minimal Viability Check:** At least one custom entity category with at least one property is defined. The relationship between this custom schema and any existing **World Foundation** is clear (e.g., it extends, overrides, or operates independently).

## Integrity Rules

*   **Source Exclusivity:** A World Codex must have a defined source. It must be either based on a **World Foundation** or built on a **Custom Codex Schema**. It can use both, but it cannot have neither.
*   **Schema Integrity:** All rules from the previous version apply (unique category/property names, valid relationships, no circular dependencies).
*   **Foundation Precedence:** If a Custom Schema is used to extend a World Foundation, the rules of deviation and scope defined in the Foundation must be respected. The system should flag attempts to define custom schema elements that directly violate a "no deviation" rule.

## Application & Utility

The function of this component remains the same, but the source of its data is now more flexible.
*   **Fact Logging Engine:** Will log user-declared facts against the **Custom Codex Schema**. If a **World Foundation** is in use, it will treat the external knowledge base as a read-only, pre-populated codex.
*   **Consistency Checker:** Queries are now federated. The system will first check for an entry in the custom codex. If not found, and a **World Foundation** exists, it will query its knowledge of that foundation. It will flag contradictions between user declarations and the established foundation based on the "Rules of Deviation."
*   **Generative Oracle:** If the source is `Generative`, the system will create and log new lore as needed to answer questions or advance the narrative, ensuring that once a fact is generated, it remains consistent.
*   **Prompt Augmentation:** Injects context into prompts from the appropriate source—either the custom-defined entries or the general knowledge of the World Foundation.
